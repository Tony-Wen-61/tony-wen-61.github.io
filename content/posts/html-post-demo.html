✨ 欢迎来到 HTML 渲染测试页！

这是一篇直接用 .html 格式编写的 Hugo 文章。

由于是纯 HTML 代码，我们可以直接在这里使用各种 CSS 内联样式、结构标签以及交互脚本，而不需要受限于 Markdown 语法。

📂 HTML 格式的优势

  • 完全的样式控制：可以直接使用 style 属性或外部样式表自定义布局。
  • 丰富的媒体嵌入：可以非常方便地加入自定义的 <iframe>、音频或视频播放器。
  • 原生的交互体验：可以直接在页面中编写 <script> 脚本来实现动态交互。
